# ResiTrack – página funcional (simulada)
- index.html: aplicación de una sola página. Base de datos relacional en el navegador (PK/FK/UNIQUE/CHECK validados en JS, persistencia localStorage), contraseñas con sal + SHA-256, permisos por rol.
- schema.sql: el mismo modelo en SQL (probado en SQLite). Para SQL Server hay que adaptar tipos (no probado).
- Logos oficiales TecNM/ITM: pegar como data URI en el objeto LOGOS dentro de index.html.
- Todo (pagos, facturas, documentos) es simulado y sin validez fiscal/oficial.
